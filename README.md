Welcome to **Scientific Calculator**, a sleek and intuitive web application designed to help you perform engineering, business, and everyday calculations with ease. Built with modern web technologies, it offers a premium user experience with a focus on simplicity and functionality.

## ✨ Key Features

- **🚀 Advanced Math**: Quick access to scientific functions, powers, roots, and constants.
- **📱 Fully Responsive**: Optimized for desktops, tablets, and mobile devices.
- **💾 Lightweight & Fast**: Runs instantly with no installation or backend required.
- **🎨 Premium UI**: Glassmorphic overlays, smooth transitions, and a high-contrast modern layout.
- **🧭 Built-in Examples**: Left and right guide panels show practical usage examples for root, trig, power, memory, and business calculations.
- **⌨️ Keyboard Friendly**: Type numbers and operators directly, use Enter to calculate, Backspace to delete, and Escape to clear.
- **⚡ Real-time Updates**: Interactive button handling ensures fast and dynamic calculation feedback.

## 🚀 Getting Started

No servers or complex installations are required! Simply follow these steps:

1. **Clone or Download**: Save the project files to your local machine.
2. **Open the App**: Locate the `index.html` file in the project folder.
3. **Launch**: Double-click `index.html` to open it in your favorite web browser.

You can also serve it locally with:

```bash
python -m http.server 8000
```

**Then visit**:

- Live Demo: https://scientific-calculator-omega-eight.vercel.app
- Local: http://127.0.0.1:8000

## 📖 Usage Guide

1. **Basic Calculations**
   - Use the on-screen buttons to enter numbers and operators.
   - Tap `=` to evaluate the expression.

2. **Scientific Functions**
   - Use `sin`, `cos`, `tan`, `asin`, `acos`, `log`, `ln`, `√`, and power helpers.
   - Toggle `DEG` / `RAD` for angle-based calculations.

3. **Memory Tools**
   - Use `MC`, `MR`, `M+`, and `M-` to store and recall values.

4. **Engineering Helpers**
   - Use `1/x`, `|x|`, `n!`, `mod`, `x²`, and `x³` for common engineering and technical work.

5. **Quick Examples**
   - Read the left and right guide panels for ready-to-use examples such as root, trig, logarithms, modulus, percentages, and memory operations.

6. **Keyboard Support**
   - Type directly with the keyboard.
   - Press `Enter` or `=` to calculate.
   - Press `Backspace` to delete.
   - Press `Escape` to clear.
